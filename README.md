📊 Sales & Inventory Analysis Dashboard

This project contains a Microsoft Excel dashboard created to analyze and monitor sales performance, inventory status, and key business metrics. It provides a quick overview of trends, stock levels, and product performance to support data-driven decision-making.


---

📁 Project Files

Sales and Inventory Analysis.xlsx
Contains:

Raw data (sales & inventory records)

Cleaned and structured datasets

PivotTables for analysis

An interactive dashboard visualizing KPIs




---

🎯 Objectives of the Analysis

Track monthly and yearly sales performance

Identify best-selling and low-performing products

Monitor stock levels and inventory status

Provide insights that help prevent stock-outs and overstocking

Support business planning using data-driven insights



---

📈 Key Features of the Dashboard

Total sales summary

Product-level performance analysis

Top and bottom product categories

Inventory quantity monitoring

Automated PivotTables for data exploration

Clean, business-ready visual dashboard



---

🔧 Tools & Techniques Used

Microsoft Excel

PivotTables & PivotCharts

Slicers

Data cleaning & transformation

Conditional formatting

Basic formulas (SUM, IF, percentage calculations, etc.)



---

🚀 How to Use the Dashboard

1. Download the Excel file.


2. Open on a laptop or desktop (slicers won’t work on mobile).


3. Refresh PivotTables if you update the raw data.


4. Use slicers to filter by:

Product

Category

Month or Date range





---

📌 Limitations

Slicers and Pivot features may not work on mobile Excel.

Dashboard is optimized for desktop viewing.
